Cozy Space Pixel Font — three pixel fonts for games (Regular, Bold, Mono)

A small, friendly pixel font in three styles. 7 px capitals, 5 px lowercase,
real descenders, accents for Spanish, French, Portuguese and German, and a few
game symbols (heart, star, arrows, music note).

ttf/      CozySpacePixel-Regular.ttf, CozySpacePixel-Bold.ttf, CozySpacePixelMono-Regular.ttf
          Install them, or load them in Godot, Unity, GameMaker, Construct, Phaser...
          Crisp at 10, 20, 30, 40 px... (one pixel = 1/10 of the font size).
          Turn off antialiasing / use nearest filtering in your engine for sharp pixels.
woff/     the same fonts for web pages (@font-face)
bmfont/   bitmap fonts in AngelCode BMFont text format (.fnt + .png), 12 px line,
          white glyphs so you can tint them in the engine. Godot 4 imports .fnt
          directly; also Phaser, libGDX, MonoGame, LÖVE and others.

Mono: every character is 6 px wide (5 + 1 space), good for scores, timers,
dialog boxes and menus that must line up.
